Kebijakan Privasi KasirKu POS

Terakhir diperbarui: 24 Oktober 2026

Kebijakan Privasi ini menjelaskan bagaimana KasirKu POS mengelola informasi pengguna saat menggunakan aplikasi kasir.

1. Data yang Disimpan

KasirKu POS digunakan untuk mengelola produk, stok barang, transaksi, pelanggan, pengaturan usaha, dan laporan penjualan. Data usaha disimpan secara lokal pada perangkat pengguna. Jika aplikasi tidak menggunakan server, pengembang tidak menerima data usaha tersebut melalui server pengembang.

2. Penggunaan Google Drive

Pengguna dapat menghubungkan akun Google untuk menggunakan fitur pencadangan dan pemulihan data. Fitur ini dapat meminta izin Google Drive dengan scope https://www.googleapis.com/auth/drive.file.

Scope tersebut memberikan akses terbatas pada file yang dibuat atau dibuka melalui aplikasi sesuai ketentuan Google. Aplikasi menggunakan akses ini untuk fitur backup dan ekspor file yang didukung. Aplikasi tidak meminta akses penuh ke seluruh Google Drive pengguna melalui scope tersebut.

File backup disimpan di Google Drive milik pengguna sendiri. Pengguna bertanggung jawab menjaga keamanan akun dan file backup mereka.

3. Informasi Akun Google

Jika pengguna menghubungkan akun Google, aplikasi dapat menggunakan alamat email untuk menampilkan identitas akun yang sedang terhubung dan mendukung fitur integrasi Google. Informasi yang benar-benar diakses bergantung pada izin yang diberikan pengguna dan implementasi aplikasi.

4. Penggunaan dan Pembagian Data

Data yang diakses melalui Google API hanya digunakan untuk menyediakan fitur yang diminta pengguna. Data tidak dijual kepada pihak ketiga. Data tidak dibagikan kepada pihak ketiga kecuali diperlukan untuk menyediakan fitur yang diminta, diwajibkan oleh hukum, atau diizinkan oleh pengguna.

Penggunaan data dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use yang berlaku.

5. Izin Perangkat

  • Kamera: dapat digunakan untuk memindai barcode atau memotret produk jika fitur tersebut tersedia.
  • Bluetooth atau perangkat di sekitar: dapat digunakan untuk mencetak nota menggunakan printer yang didukung jika fitur tersebut tersedia.

6. Keamanan dan Penyimpanan Data

Pengguna disarankan menjaga keamanan perangkat, menggunakan kunci layar, dan menyimpan backup secara berkala. Pengembang tidak dapat menjamin pemulihan data lokal apabila perangkat hilang, rusak, atau aplikasi dihapus tanpa backup.

7. Penghapusan Data dan Pencabutan Akses

Pengguna dapat mencabut akses Google melalui pengaturan akun Google di Google Account Permissions . File backup di Google Drive dapat dihapus langsung oleh pengguna. Data lokal dapat terhapus saat aplikasi dihapus, bergantung pada sistem operasi dan mekanisme penyimpanannya.

8. Perubahan Kebijakan Privasi

Kebijakan ini dapat diperbarui apabila terdapat perubahan fitur, pengelolaan data, atau ketentuan yang berlaku. Versi terbaru akan dipublikasikan pada halaman ini.
